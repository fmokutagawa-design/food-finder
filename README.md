# 今夜、どこ食べる？

綱島・新綱島周辺の15店舗について、指定日時の通常営業、距離、予算、予約、持ち帰り・配達、媒体別点数、料理写真、メニュー、媒体リンクを一枚にまとめる静的Webアプリです。

## 実行

依存関係はありません。`index.html` を開くか、ローカルHTTPサーバーで配信します。

```sh
python3 -m http.server 8000
```

## データ方針

- `data.js` の営業時間は原則として公式店舗ページ・運営会社・地域商店街の公開情報を使用します。
- 媒体名は検索リンクであり、掲載・評価点を保証する表示ではありません。
- 媒体別点数は `checked` と同日に確認したスナップショットです。媒体ごとの尺度を平均化せず、件数と確認日を併記します。
- 写真は店舗公式と一致確認できたものだけをカードへ表示し、それ以外は写真ページへの導線に留めます。
- 通常営業時間からの機械判定であり、臨時休業、貸切、満席、特別営業時間は保証しません。
- `checked` はこのアプリ側で情報源を確認した日です。
- `confidence: high` は店舗または運営会社の公式ページ、`medium` は公式アカウント・商店街等の準公式情報です。
